🎯 **Anti-Doping Awareness Web Platform — HTML / CSS / JavaScript**

Turning Sports Ethics into Interactive Digital Learning

---

📌 **Project Mission**
Doping doesn’t just break rules — it breaks **health, fairness, and trust** in sport.

This project transforms anti-doping concepts into a **multi-page, interactive learning experience** that helps answer:

* How can we make athletes and students aware of doping risks?
* How do we explain rules and banned substances in a simple way?
* How can stories and quizzes make ethics more memorable?
* How can technology support awareness campaigns and education?

This website bridges **sports ethics** with **modern web development**, showing how code can drive **real-world awareness**.

---

🔍 **Experience Highlights**

🧩 **Multi-Page Learning Journey**

* Home, Story, Quiz, Rules, Banned Substances, About Us, Login, Feedback
* Structured like a complete educational micro-site

📖 **Story-Driven Awareness**

* Multi-page story flow (`story_main.html`, `pg1.html`–`pg8.html`)
* Shows emotional, ethical, and practical impact of doping decisions

🎮 **Interactive Quiz System**

* Multiple quiz pages: `quize main.html`, `q.html`, `q2.html`, `q3.html`
* JavaScript-based question–answer logic (`q.js`, `q2.js`, `q3.js`)
* Designed to reinforce learning, not just display information

📜 **Rules & Banned Substances Library**

* `Rules.html` and `Sports and banned substancess.html`
* Acts as a quick-reference knowledge base for users

💬 **User Engagement & Feedback**

* `feedback.html` lets users share thoughts and suggestions
* `AboutUspage.html` explains mission and context
* `Mlogin.html` lays UI foundation for future authenticated experiences
